# Випассана: пали → русский (колода Anki)

[![скачать vipassana-pali-ru.apkg](https://img.shields.io/badge/%D1%81%D0%BA%D0%B0%D1%87%D0%B0%D1%82%D1%8C-vipassana--pali--ru.apkg-b5523b)](https://github.com/odinokov/vipassana-pali-anki-ru/releases/latest/download/vipassana-pali-ru.apkg) [![license CC0-1.0](https://img.shields.io/badge/license-CC0--1.0-lightgrey)](LICENSE) ![карточек 286](https://img.shields.io/badge/%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%B5%D0%BA-286-8a7f72)

286 карточек с палийскими терминами випассаны (традиция С. Н. Гоенки и тхеравада в целом). На каждой карточке показано, в какой ветке иерархии стоит термин.

## Пример карточки

**Лицевая сторона:** *paññā* — па́ння

**Оборот:**

> **Перевод:** мудрость, понимание
>
> **Пояснение:** Понимание реальности на собственном опыте: непостоянство (*anicca*), страдание (*dukkha*), безличность (*anattā*). Развивается в випа́ссане.
>
> **Место в системе:**
> - Основы → *tisikkhā* (три тренировки) → *paññā*
> - Благие качества → *bodhipakkhiyā dhammā* (37 качеств, ведущих к пробуждению) → *pañcindriya* (пять способностей) → *paññā*
> - Благие качества → *bodhipakkhiyā dhammā* → *pañcabala* (пять сил) → *paññā*
> - Благие качества → *dasa pāramiyo* (десять совершенств) → *paññā*
>
> **Включает:** *sammā-diṭṭhi* — правильное воззрение; *sammā-saṅkappa* — правильное намерение; *tisso paññā* — три вида мудрости
>
> **См. также:** *vipassanā* — прозрение, видение как есть; *tilakkhaṇa* — три характеристики; *amoha* — незаблуждение; *dhamma-vicaya* — исследование дха́мм
>
> **Противоположность:** *moha* — заблуждение

«Место в системе» есть на каждой карточке; «Включает», «См. также» и «Противоположность» — только там, где есть что показать.

## Установка

1. Скачайте файл [`vipassana-pali-ru.apkg`](https://github.com/odinokov/vipassana-pali-anki-ru/releases/latest/download/vipassana-pali-ru.apkg) из последнего релиза.
2. Откройте его в программе Anki на компьютере: двойной щелчок по файлу или импорт из меню.
3. Колода «Випассана» появится в списке колод.
4. Чтобы колода попала в AnkiWeb и на телефон, выполните синхронизацию.

Колоду можно также взять на AnkiWeb: https://ankiweb.net/shared/info/456496234

## Структура

Одна колода «Випассана», девять подколод:

| Подколода | Карточек |
|---|---:|
| 1 Основы | 40 |
| 2 Учение | 55 |
| 3 Ум и материя | 17 |
| 4 Практика | 27 |
| 5 Загрязнения | 29 |
| 6 Благие качества | 36 |
| 7 Прозрение | 51 |
| 8 Курс и традиция | 12 |
| 9 Источники | 19 |
| **Всего** | **286** |

Карточка лежит в подколоде одной из своих веток; внутри подколоды общее понятие идёт раньше частного.

Теги повторяют иерархию, например `Випассана::1_Основы::tisikkha::panna`, поэтому в браузере карточек можно открыть любую ветку.

Тип карточки один: «Пали → русский». Поля: Термин, Чтение, Перевод, Пояснение, Онтология, Включает, Связи, Противоположность. Звука и картинок нет.

## Что на обороте и условности

- Перевод и короткое пояснение; в большинстве пояснений ключевые понятия даны с пали в скобках. Где русская формулировка традиции Гоенки отличается от общепринятой, перевод начинается с неё, а буквальное значение стоит в скобках.
- «Включает» и «См. также» ведут на другие карточки колоды; «См. также» работает в обе стороны. «Противоположность» иногда называет термин, у которого нет своей карточки.
- Отдельные слова даны, как правило, в словарной форме; словосочетания и слова из формул — в именительном падеже, как в суттах (*ariyo aṭṭhaṅgiko maggo*, *svākkhāto*). Исключения — четыре устоявшихся названия в словарной форме (*yoniso manasikāra*, *khaṇika samādhi*, *upacāra samādhi*, *appanā samādhi*) и названия сутт (*Kālāma Sutta*).
- Ударения в чтении поставлены по классическому правилу пали. В четырёх составных словах они даны по устоявшемуся чтению: адуккхамасу́кха, анапанаса́ти, дхаммапа́да, аттхака́тха. «Бу́дда» и «санса́ра» даны в привычном русском написании.
- Долгота гласных в чтении не показана. Удвоенные согласные показаны, кроме *jj* и *yy*: ави́джа, ма́джхима, боджха́нга, опане́йико.

Полный текст условностей — в описании колоды «Випассана» внутри Anki.

## Источники и оговорки

- Ссылки на палийский канон: DN, MN, SN, AN, Dhp, Snp (*Sutta-nipāta*). Расшифровка — в подколоде «9 Источники». Остальные тексты названы полностью (*Itivuttaka*, *Visuddhimagga*, *Paṭisambhidāmagga*).
- Не все названия взяты из сутт: часть — из комментариев и Абхидхаммы. Основные толкования из комментариев, Абхидхаммы, *Visuddhimagga* и традиции Гоенки помечены в карточках.
- 16 знаний прозрения даны по схеме Махаси Саядо. В его «Progress of Insight» отдельным пунктом считается ещё *vuṭṭhānagāminī-vipassanā*, поэтому там номера начиная с 12-го больше на единицу.
- Колода подготовлена с помощью ИИ (Claude); ссылки на сутты сверены с SuttaCentral, написание терминов — с Digital Pāli Dictionary.

## Сборка

Карточки лежат в виде текстовых YAML-файлов в папке `dict/`, по одному на подколоду; остальные части колоды (тип карточки, шаблон, оформление, описание) — в `deck/`. Пакет собирается так (нужен Python 3.10 или новее):

```
pip install pyyaml
python3 build.py
```

Результат — файл `vipassana-pali-ru.apkg`.
